AI CLIPPER - WINDOWS

1. Unzip this folder somewhere permanent (e.g. Documents\AIClipper). Don't run it from inside the zip.
2. Double-click AIClipper.exe.
   If Windows says "Windows protected your PC", click "More info" -> "Run anyway".
   (This appears because the app isn't code-signed.)
3. Your browser opens AI Clipper. Pick an editing level and press GET CLIPS.
   No keys or accounts are needed - it's free.
   Keep the black window open while it runs - closing it quits the app.

Your files (all next to AIClipper.exe):
  output\       finished clips (.mp4 + thumbnail + caption .txt)
  config.yaml   settings: channels to watch, search topics, strictness
  .env          optional extra keys (not needed)
  assets\       optional music, sound effects, b-roll and fonts for pro/extreme levels

Check your setup: open a Command Prompt in this folder and run  AIClipper.exe doctor
If YouTube says "confirm you're not a bot": in config.yaml set  cookies_from_browser: chrome
